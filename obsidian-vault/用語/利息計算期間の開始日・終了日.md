# 利息計算期間の開始日・終了日（Accrual Start Date、Accrual End Date）

日割りで利息を計算する期間の始まりと終わりの日のこと。経過利子では、前回の利払日から受渡日までが対象となる。

> [!example] 実務シーン
> スワップの事務担当が、半年ごとの固定金利側の利息を出すため、4月1日を始まり、9月30日を終わりとする日付を登録し、その間の182日にACT/365を当てはめた。
